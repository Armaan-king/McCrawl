- `src/main.rs`: binary entry point; still the placeholder "Hello, world!" (CLI comes in Task 12).
- `src/urlnorm.rs`: `normalize(base, href) -> Option<Url>`: resolve; drop the fragment, empty query and credentials; strip a trailing host dot; RFC 3986 percent normalization in path and query (decode unreserved, uppercase other hex, leave malformed escapes); http(s) only; ≤ 2048 chars; no path segment repeated > 3 times. Idempotent and `host_key(&Url) -> Option<&str>` (lowercase hostname, the politeness key). Depends on: `url`. Used by: `frontier` (`host_key`), `parse` (`normalize`); planned: `crawler`. Tested by: `tests/urlnorm.rs`.
- `src/dedup.rs`: `url_hash`/`body_hash` (xxh3_64), `hamming`, `simhash` (64-bit SimHash over lowercase word 3-shingles; empty → 0), `SeenSet` (HashSet<u64> of URL hashes; `insert` → true if new), `NearDupIndex` (Manku 4×16-bit block tables; `find`/`insert`), `NEAR_DUP_BITS = 3`. Depends on: `url`, `xxhash-rust`. Used by: `frontier` (SeenSet), `store` (NearDupIndex); planned: `crawler` (simhash, body_hash). Tested by: `tests/dedup.rs`.
- `src/robots.rs`: `RobotsRules { AllowAll, Parsed(Robot), Unreachable }`. `from_response(status, body, agent)` follows RFC 9309: 2xx parse, 4xx AllowAll, 429/5xx/other Unreachable. If texting_robots rejects the whole file (one `$` rule over its 42 KB pattern limit), it retries via `strip_end_anchors`: `$` removed from Disallow lines and `$` Allow lines dropped, so never less strict. AllowAll is only the last resort, which no test input could reach. `allowed(&Url)` (Unreachable → false). `crawl_delay()` never panics and is capped at `MAX_CRAWL_DELAY` = 24 h. `robots_url(&Url)`. Depends on: `texting_robots`, `url`. Used by: `frontier`; planned: `crawler`. Tested by: `tests/robots.rs`.
- `src/frontier.rs`: the pure two-heap frontier (time passed in as `now`). Per-host `BinaryHeap` queues; `waiting` min-heap by `next_allowed`; `ready` max-heap by best priority; each host in at most one of {waiting, ready, in flight}. API: `push` (seen-set dedup), `requeue` (retries), `next(now) -> Next {Job, WaitUntil, Idle, Done}`, `complete_page(host, Outcome, now)`, `complete_robots(host, RobotsRules, elapsed, now)`, `is_done`, `host_name`, `stats`. Types: `UrlEntry` (seed/child, priority = -depth), `Job {Robots, Page}`, `Outcome`, `FrontierConfig`, `FrontierStats` (Serialize, for the report). Politeness: `delay = max(base, min(base × backoff, max_backoff))`, at least Retry-After (≤ 24 h), where `base = max(crawl_delay, min_delay, k × elapsed)`. Backoff ×2 on 429/503, ÷2 on success. A host dies after `max_host_failures` in a row, or after `max_robots_attempts` unreachable robots fetches (retried at robots_retry × 2^(n−1)). Robots TTL 24 h. Per-host cap drops the rest of the queue. Depends on: `urlnorm`, `dedup`, `robots`, `url`, `serde`. Used by: `metrics` (FrontierStats); planned: `crawler`. Tested by: `tests/frontier.rs`.
- `src/parse.rs`: `parse(page_url, html) -> Parsed { title, text, canonical, noindex, nofollow, links: Vec<Link { url, anchor, nofollow }> }` in one lol_html streaming pass (no DOM; `RefCell` state shared by handlers). Strict mode is off, because lol_html's default stops reading at a `<script>` inside `<select>` or after `<frameset>`. `<meta charset>` switches the encoding, unless a UTF-8 BOM (stripped) settles it. First `<base href>` only; links and canonical are resolved against it via `urlnorm::normalize`, and bad hrefs are dropped without leaking their text into the previous anchor. The anchor is the `<a>`'s Data text plus image `alt`. `rel`/meta tokens are case-insensitive token matches; meta robots handles `noindex`/`nofollow`/`none`. Title is the first HTML (RCData) `<title>`, not an SVG one. Text is Data-type text only (no script/style/title/textarea/noscript), with a space after every text node. Title, text and anchors are decoded and whitespace-collapsed once at the end. `decode_entities` (pub) handles all numeric refs (NUL/surrogate/out-of-range → U+FFFD, 0x80–0x9F → Windows-1252) and 144 named ones (Latin-1 + HTML 4 specials, cross-checked against the HTML5 table); `;` is required and unknown refs are kept as written. Known limits (`ponytail:`): links before `<base>`, links inside `<noscript>`, HTTP-header charset. Depends on: `urlnorm`, `lol_html`, `url`. Used by (planned): `crawler`. Tested by: `tests/parse.rs`, `tests/mockweb.rs` (parses mock pages).
- `src/mockweb.rs`: a deterministic synthetic web for tests and benchmarks. One axum server on `127.0.0.1` serves every `h{i}.mock` host, chosen by the `Host` header (port stripped, lowercased).
  - **Hosts:** `behavior(host % 10)`: 0 DisallowPrivate (robots.txt disallows `/private`, and its pages link there), 1 CrawlDelay2, 2 RobotsDown (503), 3 RateLimited (every 3rd page request → 429 + `Retry-After: 2`, an atomic per-host counter), 4–9 Normal (robots.txt 404).
  - **Pages:** `page_html(cfg, port, host, page)` is deterministic (SplitMix64 seeded by xxh3 of host and page). It builds `page_words` words from a 4,096-word vocabulary, with `links_per_page` links spread through the text; `cross_host_pct` % of them are absolute cross-host links carrying the port. Every page with `page % 10 == 9` copies the page before it except for the title (a planted near-duplicate).
  - **Routes:** `/` (= page 0), `/p/{n}`, `/private/{n}`, `/robots.txt`, `/big` (3 MiB), `/redirect` (301 → `/p/0`), `/file.pdf`; anything else, or an unknown host, is 404. Latency is fixed per (host, path) within `latency_ms`.
  - **API:** `start(cfg, port)`, `MockWeb { addr }` with `resolve_overrides()`, `seeds(n)` and `hits()`. Every request is logged as a `Hit { host, path, at, status }`, where `at` is the arrival time, before the latency; the log has no cap (`ponytail:`).
  - **Also:** `politeness_ceiling(cfg, min_delay)` = Σ 1/max(min_delay, Crawl-delay) over hosts whose robots.txt is up; `host_name`/`host_index` (exact spelling only); `robots_txt(host)`.
  - Depends on: `tokio`, `axum`, `xxhash-rust`, `url`. Used by: `tests/fetch.rs`; planned: `crawler` tests, `tests/politeness.rs`, the `mockweb`/`bench` CLI. Tested by: `tests/mockweb.rs`.
- `src/fetch.rs`: `Fetcher::new(&FetchConfig { user_agent, connect_timeout, timeout (whole request), max_body, resolve })` builds two reqwest clients with the same settings (User-Agent, `Accept`, timeouts, `pool_max_idle_per_host(1)`, DNS overrides). The page client follows no redirects (the crawler queues the target itself); the robots client follows up to 5 (RFC 9309). `Accept` is `text/html,…` for pages and `text/plain,*/*` for robots.txt.
  - `fetch_page(&Url)` reads the body only for HTML (`text/html` or `application/xhtml+xml`, case-insensitive, parameters ignored; a missing type is not HTML). `fetch_robots(&Url)` reads any type.
  - **Bodies:** decoded (gzip/br/zstd), capped at `max_body` bytes after decoding (decompression bombs stop at the cap). The fetch returns as soon as the cap is reached, without waiting for the rest; the buffer reservation is capped too, so a hostile `Content-Length` can't allocate.
  - **`FetchResponse`:** `status`, `http_head`, `is_html`, `content_type`, `location` (lossy UTF-8, as browsers accept raw UTF-8), `retry_after`, `body`, `truncated`, `elapsed` (from send to end of body, for the adaptive delay).
  - **`http_head`:** the WARC header block: `HTTP/1.1 {code} {canonical reason}`, then the headers with their raw bytes, minus `Transfer-Encoding` and the server's `Content-Length`, plus `content-length: {body.len()}`. `Content-Encoding` is kept, because reqwest only removes it when it actually decoded the body, so one still present is true of the stored bytes.
  - **`FetchError`:** `Timeout`, `Connect(msg)` (DNS, refused, TLS), `Other(msg)` (bad HTTP, cut-off body, corrupt gzip, more than 5 robots redirects). `retryable()` = Timeout or Connect; `kind()`; Display `kind: cause chain`, without the URL.
  - `parse_retry_after`: delta-seconds only (digits; too big saturates; the frontier caps at 24 h). The HTTP-date form gives None (`ponytail:`).
  - Depends on: `reqwest`, `url`. Used by (planned): `crawler`. Tested by: `tests/fetch.rs`.
- `src/store.rs`: the one writer of a crawl's output, on its own thread.
  - **Types:**
    - `PageRecord`: one `pages.jsonl` row per fetch, errors and non-HTML included. Fields: url, host, depth, parent_url, priority, fetched_at (unix ms), status, error, content_type, bytes, truncated, title, text, canonical, noindex, links (`LinkOut { url, anchor, nofollow }`), simhash, body_hash, near_dup.
    - `WarcPayload { http_head, body, truncated }`, `StoreMsg { record, simhash, body_hash, warc }`.
    - `StoreSummary { records, warc_records (responses only), warc_files, exact_dups, near_dups }` (Serialize).
  - `iso8601(unix_secs)`: Hinnant's civil-from-days, unsigned, never panics.
  - `warc_record(kind, target, date, content_type, extra, payload, id)`: WARC/1.1 framing. Header order: Type, Record-ID, Date, Target-URI (optional), `extra`, Content-Type, Content-Length; then the payload and CRLF CRLF.
  - **`WarcWriter`:** `create(dir, rotate_at)`, `write_response(url, unix_secs, &WarcPayload)`, `flush`.
    - Writes files `crawl-NNNNN.warc.gz`. Each starts with a `warcinfo` record (`WARC-Filename`; software, format and conformsTo fields).
    - Every record is its own gzip member, compressed into a reused buffer, so the body is never copied. A capped body gets `WARC-Truncated: length`.
    - Rotation is checked before each response: once the file has reached `rotate_at` compressed bytes and something has been archived. So no file is only a `warcinfo`, except the only file of an empty crawl.
    - Files are opened with `create_new`, so an earlier crawl is never overwritten.
    - Record IDs are RFC 9562 version-8 UUIDs from xxh3_128(clock nanos, pid, a process-wide counter).
  - **`Store`:** `open(dir, rotate_at)`, `write(StoreMsg)`, `finish() -> StoreSummary`.
    - `open` creates the directories, then `pages.jsonl` and the first WARC file, both `create_new`.
    - `write`, exact duplicates: a `body_hash` seen before, of any value (0 included).
    - `write`, near duplicates: `NearDupIndex` for a nonzero SimHash (0 means no text and is not indexed). `near_dup` is the earliest page found. Every fingerprint is indexed, near duplicates too, so chains match.
    - `write`, fields: the store sets `simhash` and `body_hash` (16-digit hex) and `near_dup` itself, replacing whatever the caller put there. The WARC response is written first (date = fetched_at / 1000), then the JSON line.
  - **`spawn(store, rx)`:** a thread named `store`. It writes until every sender is dropped and flushes whenever the channel runs empty. On a write error it returns `Err`, and senders see a closed channel; the crawler must treat that as fatal (Task 11).
  - **Known limits (`ponytail:`):** gzip at level 6 on one thread; indexed URLs kept in RAM (u32 ids).
  - Depends on: `dedup` (NearDupIndex), `flate2`, `serde`, `serde_json`, `tokio` (mpsc), `xxhash-rust`. Used by: `metrics` (StoreSummary); planned: `crawler`. Tested by: `tests/store.rs`.
- `src/metrics.rs`: crawl statistics, owned by the scheduler alone (plain fields, no atomics).
  - **`Tally`:**
    - Fields: pages (responses, any status), bytes, `status` histogram, `errors` by `FetchError::kind`, retries, redirects, non_html, robots_fetches, `latencies_ms` (one per response), `idle_slot` (time with a free slot but no host allowed: the cost of politeness).
    - `page(status, bytes, elapsed)` counts one response; latency is whole milliseconds, saturating at u32::MAX.
    - `report(wall, FrontierStats, StoreSummary) -> Report` sorts the latencies and samples CPU and peak RSS. `progress_line(wall, &FrontierStats)` gives one stderr line.
  - **`Report`** (Serialize, becomes `report.json`): wall_secs, pages, pages_per_sec (0, not infinity, for zero time, because serde_json writes infinity as null), bytes, status, errors, retries, redirects, non_html, robots_fetches, idle_slot_secs, latency_p50_ms/p99_ms, cpu_secs and peak_rss_mb (`None` off Linux), frontier, store. Config is not included; Task 11 adds it to `report.json`.
  - `percentile(sorted, p)`: nearest rank, ceil(p·n) clamped to 1..=n. The product is shaved by 1e-12, so float error can't move the rank; p outside 0..=1 (or NaN) acts as the nearest end; empty gives 0.
  - **`/proc` readers:** `parse_vmhwm_kb(status)` (the `VmHWM:` line, `kB` required) and `peak_rss_mb()` (MiB). `parse_cpu_secs(stat)` reads fields 14 and 15 after the last `)` (the command name may contain `)`), in ticks of 1/100 s, added as f64 so it can't overflow; `cpu_secs()` reads it live.
  - Known limit (`ponytail:`): latencies kept as a Vec (4 B/page).
  - Depends on: `frontier` (FrontierStats), `store` (StoreSummary), `serde`. Used by (planned): `crawler`, the `bench` CLI. Tested by: `tests/metrics.rs`.

  - `tests/robots.rs`: status semantics and boundaries (0–999), agent-specific group, Crawl-delay values (inf/1e30/NaN/negative/fractional), odd and binary files, a 20k-rule file, matching details (Allow precedence, `*`, `$`, query rules, case-insensitive agents), an oversized `$` rule not voiding the rest (`\n`, `\r\n` and `\r` line endings), robots URL edge cases.
