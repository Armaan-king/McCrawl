- `Cargo.toml`: crate `mccrawl`, edition 2024. Deps: `url`, `xxhash-rust` (xxh3), `texting_robots`, `lol_html`, `tokio` (rt-multi-thread, macros, net, time, sync, signal, io-util), `axum` (default features off; `tokio` + `http1` only). Used by: `cargo`.
- `Cargo.lock`: generated lockfile. Depends on: `Cargo.toml`.

- `src/lib.rs`: `pub mod` declarations (`dedup`, `frontier`, `mockweb`, `parse`, `robots`, `urlnorm`). Used by: `src/main.rs` (later), `tests/`.
- `src/main.rs`: binary entry point; still the placeholder "Hello, world!" (CLI comes in Task 12).
- `src/urlnorm.rs`: `normalize(base, href) -> Option<Url>`: resolve; drop the fragment, empty query and credentials; strip a trailing host dot; RFC 3986 percent normalization in path and query (decode unreserved, uppercase other hex, leave malformed escapes); http(s) only; ≤ 2048 chars; no path segment repeated > 3 times. Idempotent and `host_key(&Url) -> Option<&str>` (lowercase hostname, the politeness key). Depends on: `url`. Used by: `frontier` (`host_key`), `parse` (`normalize`); planned: `crawler`. Tested by: `tests/urlnorm.rs`.
- `src/dedup.rs`: `url_hash`/`body_hash` (xxh3_64), `hamming`, `simhash` (64-bit SimHash over lowercase word 3-shingles; empty → 0), `SeenSet` (HashSet<u64> of URL hashes; `insert` → true if new), `NearDupIndex` (Manku 4×16-bit block tables; `find`/`insert`), `NEAR_DUP_BITS = 3`. Depends on: `url`, `xxhash-rust`. Used by: `frontier` (SeenSet); planned: `store` (NearDupIndex, hashes), `crawler`. Tested by: `tests/dedup.rs`.
- `src/robots.rs`: `RobotsRules { AllowAll, Parsed(Robot), Unreachable }`. `from_response(status, body, agent)` follows RFC 9309: 2xx parse, 4xx AllowAll, 429/5xx/other Unreachable. If texting_robots rejects the whole file (one `$` rule over its 42 KB pattern limit), it retries via `strip_end_anchors`: `$` removed from Disallow lines and `$` Allow lines dropped, so never less strict. AllowAll is only the last resort, which no test input could reach. `allowed(&Url)` (Unreachable → false). `crawl_delay()` never panics and is capped at `MAX_CRAWL_DELAY` = 24 h. `robots_url(&Url)`. Depends on: `texting_robots`, `url`. Used by: `frontier`; planned: `crawler`. Tested by: `tests/robots.rs`.
- `src/frontier.rs`: the pure two-heap frontier (time passed in as `now`). Per-host `BinaryHeap` queues; `waiting` min-heap by `next_allowed`; `ready` max-heap by best priority; each host in at most one of {waiting, ready, in flight}. API: `push` (seen-set dedup), `requeue` (retries), `next(now) -> Next {Job, WaitUntil, Idle, Done}`, `complete_page(host, Outcome, now)`, `complete_robots(host, RobotsRules, elapsed, now)`, `is_done`, `host_name`, `stats`. Types: `UrlEntry` (seed/child, priority = -depth), `Job {Robots, Page}`, `Outcome`, `FrontierConfig`, `FrontierStats`. Politeness: `delay = max(base, min(base × backoff, max_backoff))`, at least Retry-After (≤ 24 h), where `base = max(crawl_delay, min_delay, k × elapsed)`. Backoff ×2 on 429/503, ÷2 on success. A host dies after `max_host_failures` in a row, or after `max_robots_attempts` unreachable robots fetches (retried at robots_retry × 2^(n−1)). Robots TTL 24 h. Per-host cap drops the rest of the queue. Depends on: `urlnorm`, `dedup`, `robots`, `url`. Used by (planned): `crawler`, `metrics` (FrontierStats). Tested by: `tests/frontier.rs`.
- `src/parse.rs`: `parse(page_url, html) -> Parsed { title, text, canonical, noindex, nofollow, links: Vec<Link { url, anchor, nofollow }> }` in one lol_html streaming pass (no DOM; `RefCell` state shared by handlers). Strict mode is off, because lol_html's default stops reading at a `<script>` inside `<select>` or after `<frameset>`. `<meta charset>` switches the encoding, unless a UTF-8 BOM (stripped) settles it. First `<base href>` only; links and canonical are resolved against it via `urlnorm::normalize`, and bad hrefs are dropped without leaking their text into the previous anchor. The anchor is the `<a>`'s Data text plus image `alt`. `rel`/meta tokens are case-insensitive token matches; meta robots handles `noindex`/`nofollow`/`none`. Title is the first HTML (RCData) `<title>`, not an SVG one. Text is Data-type text only (no script/style/title/textarea/noscript), with a space after every text node. Title, text and anchors are decoded and whitespace-collapsed once at the end. `decode_entities` (pub) handles all numeric refs (NUL/surrogate/out-of-range → U+FFFD, 0x80–0x9F → Windows-1252) and 144 named ones (Latin-1 + HTML 4 specials, cross-checked against the HTML5 table); `;` is required and unknown refs are kept as written. Known limits (`ponytail:`): links before `<base>`, links inside `<noscript>`, HTTP-header charset. Depends on: `urlnorm`, `lol_html`, `url`. Used by (planned): `crawler`. Tested by: `tests/parse.rs`, `tests/mockweb.rs` (parses mock pages).
- `src/mockweb.rs`: a deterministic synthetic web for tests and benchmarks. One axum server on `127.0.0.1` serves every `h{i}.mock` host, chosen by the `Host` header (port stripped, lowercased).
  - **Hosts:** `behavior(host % 10)`: 0 DisallowPrivate (robots.txt disallows `/private`, and its pages link there), 1 CrawlDelay2, 2 RobotsDown (503), 3 RateLimited (every 3rd page request → 429 + `Retry-After: 2`, an atomic per-host counter), 4–9 Normal (robots.txt 404).
  - **Pages:** `page_html(cfg, port, host, page)` is deterministic (SplitMix64 seeded by xxh3 of host and page). It builds `page_words` words from a 4,096-word vocabulary, with `links_per_page` links spread through the text; `cross_host_pct` % of them are absolute cross-host links carrying the port. Every page with `page % 10 == 9` copies the page before it except for the title (a planted near-duplicate).
  - **Routes:** `/` (= page 0), `/p/{n}`, `/private/{n}`, `/robots.txt`, `/big` (3 MiB), `/redirect` (301 → `/p/0`), `/file.pdf`; anything else, or an unknown host, is 404. Latency is fixed per (host, path) within `latency_ms`.
  - **API:** `start(cfg, port)`, `MockWeb { addr }` with `resolve_overrides()`, `seeds(n)` and `hits()`. Every request is logged as a `Hit { host, path, at, status }`, where `at` is the arrival time, before the latency; the log has no cap (`ponytail:`).
  - **Also:** `politeness_ceiling(cfg, min_delay)` = Σ 1/max(min_delay, Crawl-delay) over hosts whose robots.txt is up; `host_name`/`host_index` (exact spelling only); `robots_txt(host)`.
  - Depends on: `tokio`, `axum`, `xxhash-rust`, `url`. Used by (planned): `fetch` tests, `crawler` tests, `tests/politeness.rs`, the `mockweb`/`bench` CLI. Tested by: `tests/mockweb.rs`.

  - `tests/dedup.rs`: seen-set dedup, SimHash near/far on a 2000-word fixture, block index hit/reject, case/whitespace/short texts, golden values (simhash incl. tie handling, url_hash, body_hash = reference XXH3), hamming, bucket edge cases, and a random check of the block-index guarantee (2,000 fingerprints × 0–6 flipped bits).
  - `tests/robots.rs`: status semantics and boundaries (0–999), agent-specific group, Crawl-delay values (inf/1e30/NaN/negative/fractional), odd and binary files, a 20k-rule file, matching details (Allow precedence, `*`, `$`, query rules, case-insensitive agents), an oversized `$` rule not voiding the rest (`\n`, `\r\n` and `\r` line endings), robots URL edge cases.

Edge cases: a push mid-download, priority and FIFO within a host, host independence, requeue, failure reset, dead-host pushes, robots recovery, 24 h refetch, the Retry-After cap, hostless URLs, `child`. Plus `random_operations_never_break_politeness_or_lose_urls`: a model-based random simulation (25 seeds) checking one request per host, no early contact, robots first, no disallowed URL, the cap, no dead-host jobs, and URL conservation; it also asserts that every drop path was exercised.
